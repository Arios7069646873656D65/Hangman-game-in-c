- 🔐 A simple **Hangman game**


##  Hangman Game

A command-line Hangman game created in C. The user has 6 chances to guess a hidden word by either guessing single letters or the full word.

### 🛠 Features
- Accepts both **letters** and **whole word** guesses
- **Case-insensitive** input
- Keeps track of remaining attempts
- Displays progress after each guess

###  How to Compile & Run

```bash
gcc hangman.c -o hangman
./hangman
